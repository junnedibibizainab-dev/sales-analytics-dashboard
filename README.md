# Sales Analytics Dashboard

## Project Overview
The Sales Analytics Dashboard is a beginner-friendly data analytics web application built using Python, Streamlit, Pandas, and Plotly.

It helps users analyze sales performance through interactive charts, key performance indicators (KPIs), filters, and downloadable reports.

## Features
- Total revenue and profit calculations
- Profit margin and average order value
- Monthly revenue and profit trends
- Revenue analysis by region and category
- Top-selling product analysis
- CSV data upload and basic data cleaning
- Interactive date, region, and category filters
- Download filtered sales records as CSV

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Installation and Setup

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Create a virtual environment:

   `python -m venv .venv`

4. Activate the environment on Windows:

   `.venv\Scripts\activate`

5. Install dependencies:

   `python -m pip install -r requirements.txt`

6. Run the application:

   `python -m streamlit run app.py`

7. Open the local URL displayed in the terminal.

## Dataset
The project includes a fictional sample sales dataset for practice and demonstration.

Uploaded CSV files must contain the required columns described in the application.
